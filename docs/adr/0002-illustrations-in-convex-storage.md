# All illustration artifacts in Convex, written by the generation workflow

Illustration cutouts (~130 files, ~100MB) live in Convex file storage; each species doc also carries its own mask bits (~1-2KB base64 silhouette) and dims, written by the cloud generation workflow's mask step. This supersedes the original plan to keep masks.json/dims.json static in the repo: a cloud workflow cannot commit to git, and per-doc masks keep regeneration a one-click admin action with no redeploy. No fetch waterfall is introduced — the collage query returns mask + dims alongside Prevalence in a single round trip. Trade-off accepted: packing data is no longer versioned together with the packing algorithm that consumes it, so the mask format (1-bit MSB-first row-major, base64) must stay stable or be migrated in lockstep. Considered and rejected: plain git in public/ (repo bloat, art changes need deploys), Vercel Blob (second storage system), repo-committed masks with a local rebuild script (two-step regeneration ritual).
