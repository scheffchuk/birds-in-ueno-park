# Next Cache Components on 16.3 preview; atlas + collage cached

Adopt Next.js **16.3.0-preview.9** with `cacheComponents` and `partialPrefetching` enabled together (Workflow wrapper preserved). Public atlas detail uses `'use cache'` (`cacheLife('hours')`, tags `guide-species` / `species:{slug}`); the atlas list caches the species fetch the same way (`guide-species`) and filters by Season in the `searchParams` hole. The collage uses the same pattern: `fetchQuery(api.species.listForCollage)` behind `'use cache'` (`cacheLife('hours')`, tag `guide-species`); Season filtering and packing stay client-side. Homepage image `<link rel="preload">` tags stay in a `connection()` hole so Tokyo wall-clock Season does not poison the cached species payload. `/admin` opts out with `export const instant = false`.

Public chrome fills the Partial Prerender shell via cached message catalogs (`loadMessages` + `cacheLife('max')`, keyed by Locale). Homepage brand/nav/footer resolve into the shell at build time; only request-time holes (collage image-preload Season, atlas `searchParams`) remain streaming Suspense. Avoid `getTranslations` / next-intl Link trees inside `'use cache'` — they still touch `headers()`. Fallbacks are layout-stable empty regions, not "Loading…" text. Auth providers live under `/admin` only; public routes do not mount a Convex React client. Illustration API routes drop `export const runtime = "nodejs"` (incompatible with Cache Components; Node remains the default). Generate / reject-and-regenerate bust `guide-species` and `species:{slug}` via injectable `revalidateTags` → `revalidateTag(tag, "max")` on success only.

Invalidation is TTL-first: tag busts only from those illustration Next API routes. Curated edits, Listed toggles, and approve stay Convex-direct from admin — no write-path proxy and no Convex→Next revalidate webhook for v1. Collage therefore shares atlas staleness: visitors refresh or wait for hourly TTL / generate-path busts rather than a live Convex subscription.

Considered and rejected: staying on 16.2 stable (misses 16.3 partial prefetch / shell work we want), keeping collage on `preloadQuery` + `usePreloadedQuery` for mid-session admin updates (v1 is a curated static guide; live BirdNET is v2), proxying all public-affecting admin writes through Next solely for `revalidateTag`, and a Convex webhook for cache busts.
